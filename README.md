# 📚 MindDesk

MindDesk is a modern digital study hub designed to help students organize their academic life from one beautiful dashboard.

The goal of this project is to combine planning, productivity, learning tools, and study analytics into one clean and easy-to-use web application.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/MindDesk.git
```

Go into the project:

```bash
cd MindDesk
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it.

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
